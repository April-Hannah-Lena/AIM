# Spectral/PDE screening exclusions — 2026-09-22

These candidates were not admitted. A recent proof claim is enough to withhold an entry while that claim is assessed; this file does not certify correctness of every cited preprint.

| Candidate | Reason for exclusion or narrowing |
|---|---|
| Landis conjecture for real potentials in higher dimensions | Matching counterexample claim by Frank–Ivanisvili, [arXiv:2608.00802](https://arxiv.org/abs/2608.00802). |
| Schiffer conjecture in its broad form | Matching counterexample claim, [arXiv:2608.05114](https://arxiv.org/abs/2608.05114). |
| HRT linear independence conjecture | August 2026 resolution claims, including [arXiv:2608.13539](https://arxiv.org/abs/2608.13539). |
| Gross–Pitaevskii traveling waves at every subsonic speed | Gui–Lai–Qin–Wei, [arXiv:2609.08906](https://arxiv.org/abs/2609.08906), contains matching existence claim. Uniqueness at all momentum is separately assigned to the continuum agent. |
| General Escobar lower bound for convex-boundary Steklov problems | Counterexample claim [arXiv:2608.23063](https://arxiv.org/abs/2608.23063). |
| Exponential Gelfand extremal state singularity on every high-dimensional convex domain | Thin-ellipsoid results [arXiv:2609.06673](https://arxiv.org/abs/2609.06673) invalidate the broad candidate. The retained entry asks instead whether an already singular extremal state has exactly one singular point. |

| Sharp three-dimensional curl/Hopf magnetic threshold and related sharp Faddeev–Skyrme inequalities | Wang–Zhang [arXiv:2607.23827](https://arxiv.org/abs/2607.23827) announces matching results; excluded. |
| Hyperbolic-space Weinstock inequalities | August 2026 results, including [arXiv:2608.11841](https://arxiv.org/abs/2608.11841), address those cases. The retained spherical question fixes boundary area and an open hemisphere. |
| Normalized iterates of a normal operator always form a frame | Krishtal–Pfander counterexample [arXiv:2606.20848](https://arxiv.org/abs/2606.20848). Replaced by infinite-time continuous-frame discretization. |

| Completeness for all imaginary powers through exponent 2/3 | [Tumanov, arXiv:2101.01680](https://arxiv.org/abs/2101.01680) settles exponents close to 2/3. Retained only 0 < alpha <= 1/2, outside its sufficient sector. |
| Sharp p-Poisson regularity near p=2 | [Lee–Lee, arXiv:2609.09966](https://arxiv.org/abs/2609.09966) proves a neighborhood of 2. Retained the all-p higher-dimensional endpoint conjecture. |
| General classical small-dimensional stable elliptic regularity with nonnegative reaction | Known optimal results; retained sign-changing reactions in dimensions 6–9 only. |
| Radial MEMS regularity without curvature condition | [Peng–Villegas, arXiv:2602.21115](https://arxiv.org/abs/2602.21115) resolves the radial case. Retained arbitrary smooth domains. |
| Two-dimensional off-axis-regularized self-steepening NLS, parallel derivative | The 2019 Arbunich–Klein–Sparber paper proves global results in this setting. Retained the unregularized two-dimensional equation with amplitude blow-up. |
| General supercritical defocusing NLS smooth global existence | Known singularity constructions; not safely an open statement. |
| 3D Kakeya dimension, AKLT hexagonal spectral gap, existence of exponential Riesz bases for every bounded real-line set | Matching known resolutions/counterexamples; not admitted. |
| Gaussian entanglement of formation, I3322 infinite-dimensional advantage | Recent potentially matching claims found; omitted rather than attempting to certify status. |
| Stable Bernstein hypersurfaces in R7 | Other agent identified matching September 2026 claim [arXiv:2609.15720](https://arxiv.org/abs/2609.15720); not admitted. |

All accepted entries also have individual status reviews. Searches establish what was located, not a proof of nonexistence of later literature. Existing 352 titles and nearby statements were checked before drafting; classical catalog entries such as Pólya, Ivrii, hot spots, QUE, Anderson transport, Bochner–Riesz, restriction and local smoothing were not reused.

- **p-harmonic weak unique continuation:** removed after root cross-deduplication found an exact match to existing problem 070. The strong comparison principle retained here is a different two-solution contact question.
- **Dimension-free weak-(1,1) vector Riesz bound:** excluded after checking Y. Ouyang, D. Spector and C. B. Stockdale, [arXiv:2608.18068](https://arxiv.org/abs/2608.18068), August 2026, which claims a dimension-independent constant 2. The retained sharp strong-Lp vector Riesz conjecture is distinct from this endpoint boundedness assertion.
